# Applied Economics Projects

This repository contains selected projects completed during my MSc in International Trade, Finance and Development at the Barcelona School of Economics (2025–2026).

The projects cover applied econometrics, machine learning, macroeconomic forecasting, and development economics using R, Python, and MATLAB.

## Projects

- **Structural Transformation Thesis** – Service-led structural transformation in developing economies.
- **Saudi Nowcasting** – Dynamic factor model and Kalman filter for GDP nowcasting.
- **Barcelona Rent Prediction** – Machine learning models for neighbourhood-level rent prediction.
- **Machine Learning Finance** – Option pricing using supervised machine learning techniques.
